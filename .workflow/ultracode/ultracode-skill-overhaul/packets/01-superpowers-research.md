# Packet 01-superpowers-research: primary-source workflow research

## Objective

Extract concrete, transferable workflow principles from obra/superpowers and other primary sources that should improve Ultracode.

## Context

Ultracode is a host-agnostic skill for proportional planning, delegation, integration, and verification. It must remain honest about host capabilities and lightweight for small tasks.

## Sources

- `https://github.com/obra/superpowers`
- Primary documentation linked from that repository
- Official agent/engineering workflow sources only when directly relevant

## Ownership

Read-only.

## Do

- Identify mechanisms, not slogans.
- Cite exact source URLs/files.
- Separate reusable principles from Superpowers-specific assumptions.
- Recommend no more than ten high-impact changes.

## Do not

- Edit files.
- copy branding or large text passages.
- infer unsupported runtime capabilities.

## Expected output

Summary, evidence, recommended Ultracode adaptations, and risks.

## Verification

Every recommendation must map to a primary source and a current Ultracode gap.

## Handoff format

Concise Markdown with source links.
